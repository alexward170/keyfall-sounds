# Keyfall sounds

Sound packs for [Keyfall](https://github.com/alexward170/keyfall-daw), a desktop DAW. Each pack is a `.kfpack` file: a plain tar of FLAC recordings plus a `pack.json` that maps them to keys, velocities, round robins, release samples and pedal states, with the pack's licence and credit inside. Keyfall's **Sounds** page downloads them from the [releases](https://github.com/alexward170/keyfall-sounds/releases) listed in `catalog.json`.

Every recording here comes from a library whose licence allows redistribution (CC0, CC BY, public domain). Nothing was recorded by Keyfall; the credit belongs to the people below. The packs are built by `tools/sounds` in the Keyfall repository from the original downloads, with no processing other than decoding, trimming of velocity layers for the Standard tier, and conversion to 16-bit FLAC where the source was WAV or 24-bit.
